# Features

## Core Modules

### 1. Authentication
- Officer registration with email verification
- JWT-based login with access/refresh tokens
- Role-based access control

### 2. Dashboard
- Real-time crime statistics
- Charts: crime by type, monthly trends, hotspots
- Recent FIR activity feed

### 3. FIR Management
- Create, view, edit, delete FIRs
- FIR number auto-generation (FIR-YYYY-NNNNN)
- Search, filter, pagination
- Status transition validation

### 4. Victim Management
- CRUD for victim records
- Link victims to FIRs

### 5. Accused Management
- CRUD for accused persons
- Risk scoring (0-10)
- Repeat offender tracking

### 6. Evidence Management
- Evidence recording with type categorization
- Chain of custody tracking

### 7. Financial Transactions
- Bank transaction tracking
- Support for NEFT, RTGS, IMPS, UPI

### 8. Crime Hotspots
- Geographic clustering by district
- Risk levels: Low, Medium, High
- Interactive map with Leaflet

### 9. Criminal Network
- Interactive graph visualization
- Node types: FIR, Accused, Victim, Evidence, Location, Financial
- Zoom, pan, click-to-detail

### 10. Crime Prediction
- Linear Regression forecasting
- Monthly, quarterly predictions
- Confidence intervals
- Seasonal pattern analysis

### 11. AI Chat (CrimeAI)
- Hybrid SQL + LLM architecture
- Natural language queries
- Context memory
- Kannada support
- Voice input/output
- PDF export
- Image analysis
- Explainable AI

### 12. Reports
- Automated report generation
- AI summaries
- PDF export

### 13. Audit Logging
- Track user actions
- Filter by type, user, date

## Intelligence Features
- Explainable AI with Why? section
- Context Memory for pronouns
- Demo Mode with sample data
- Investigation Timeline
- Smart Recommendations per crime type
