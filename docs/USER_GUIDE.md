# User Guide

## Quick Start
1. Register and login
2. Enable Demo Mode in top bar
3. Ask questions in the chat

## Sample Queries
- Show FIR-2026-00001
- Summarize recent theft cases
- Show victims related to murder
- Analyze hotspots in Bengaluru
- Predict crime next month
- Show criminal network

## Features
- Type in Kannada for automatic translation
- Use pronouns (it, his, her) for context memory
- Toggle Demo Mode for sample data
- Export conversations as PDF
